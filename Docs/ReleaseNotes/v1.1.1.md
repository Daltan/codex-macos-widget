## 修复 / Fixes

- 修复桌面刷新入口的 App Intent 连接超时：组件直接打开应用刷新 URL。
- 应用运行时每五分钟查询，唤醒后补查；查询结果成功保存后再重载组件，避免提前显示旧快照。
- 保留限流冷却与失败时的最近成功数据，增加刷新链路诊断日志和回归测试。

- Replace the widget's failing App Intent handoff with a direct refresh URL.
- Check usage every five minutes while the app runs and after wake; reload widgets only after the completed result is saved.
- Preserve rate-limit cooldowns and the last successful snapshot; add diagnostics and regression coverage.

## 安装与兼容 / Installation and compatibility

macOS 14+，Apple Silicon / Intel Universal。退出旧应用，解压 ZIP 或打开 DMG，将 Codex Usage.app 替换到 Applications 后启动。保持应用运行才能自动查询；关闭窗口可保留菜单栏，退出会停止查询。已有小组件可继续使用。

macOS 14+, Apple Silicon / Intel Universal. Quit the old app, extract the ZIP or open the DMG, replace Codex Usage.app in Applications, then launch it. Keep the app running for automatic queries; closing a window keeps the menu-bar process, while quitting stops queries. Existing widgets remain supported.
