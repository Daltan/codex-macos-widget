## 新功能 / What's new

- 主应用、小号与中号桌面组件现在支持英文和简体中文，跟随 macOS 首选语言。设置、错误提示、菜单、周期名称和刷新操作均已本地化。
- 修改系统语言后请重新打开应用；小组件可能需要等待 WidgetKit 重载或重新添加。
- 新增自动发布工作流：同步版本/build、测试、构建、tag、附件上传、发布和公开下载回验。失败后可继续，避免重复发版或覆盖已有附件。

The app and desktop widgets now follow macOS language preferences, with English and Simplified Chinese translations throughout. Relaunch after changing language; widgets may need a timeline reload or re-adding. Releases now use a repeatable Git/gh workflow with verified downloads and resumable draft uploads.

## 验证与限制 / Validation and limitations

- 11 项 Swift 测试、6 项发布工作流回归测试；中英文真实主应用文案回读通过。
- 小号/中号 × 明/暗 × 中/英的原生布局渲染已核对。布局渲染不等同于桌面截图；全局切换系统语言后的桌面自动重载时序仍未端到端验证。
- 每次发版验证 app/扩展版本与签名、Universal 双架构、DMG/ZIP 内容及下载散列。
- 已有大号组件仍需改用小号或中号。当前没有 Developer ID 签名或 Apple 公证；其他 Mac 首次安装与 Intel 实机仍未验证。

Eleven Swift tests and six release-workflow regression tests cover the implementation. English/Chinese app text was checked in the running app. Native layout renders cover both widget sizes and appearances, but full desktop-host behavior after a global system-language change remains unverified. Builds remain ad-hoc signed and not notarized.
