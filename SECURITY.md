# Security / 安全

Do not attach tokens, cookies, API keys, raw app-server responses, cache files, full account identifiers, or signing certificates to public issues.

For a suspected vulnerability, use GitHub's private vulnerability reporting option if available. Otherwise open a minimal issue asking for a private reporting channel without revealing exploit details or private data. Do not send secrets to demonstrate a bug.

请勿在公开 Issue 中上传 Token、Cookie、API Key、原始响应、缓存、完整账号或签名证书。疑似漏洞请优先使用 GitHub 私密漏洞报告（如可用）；否则仅发布请求私下联系方式的简短 Issue，不公开漏洞细节或私密数据。

Authentication belongs to Codex. Preserve the read-only protocol boundary, restrictive cache permissions, and last-successful-snapshot behavior when proposing fixes.
